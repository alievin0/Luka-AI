# 🏢 فريق المحاسبين الرقمي — ٢٠ وكيلًا متخصصًا

## 🚀 طرق الاستخدام

### ١. داخل Claude Code (الأسهل)
الوكلاء مثبتون في `.claude/agents/` ويعملون تلقائيًا كـ Subagents. افتح Claude Code في هذا المستودع واطلب مباشرة:

> "استخدم وكيل cb-bookkeeping وسجّل لي معاملات هذا الأسبوع: ..."

> "يا cma-management-accounting سعّر لي خدمة تصميم موقع تكلفتها كذا..."

أو دع Claude يختار المختص تلقائيًا حسب طلبك — وصف كل وكيل مكتوب ليتعرف Claude على اختصاصه.

### ٢. في تطبيق Claude أو أي نموذج ذكاء اصطناعي
انسخ محتوى `BASE.md` + ملف الوكيل المطلوب في أول رسالة (أو في تعليمات مشروع Project)، ثم ابدأ العمل. كل ملف وكيل مكتفٍ بذاته مع الأساس.

### ٣. عبر API لبناء تطبيقك الخاص
استخدم `BASE.md + ملف الوكيل` كـ System Prompt لكل وكيل، ووجّه الطلبات للوكيل المناسب.

## 🧭 من أسأل؟ (دليل سريع)

- **عمل يومي** (فواتير، قيود، مطابقة بنك) → `cb-bookkeeping`
- **نهاية الشهر** (إقفال وقوائم) → `cb-bookkeeping` ثم `acca-ifrs`
- **قرار** (تسعير، توظيف، توسع) → `cma-management-accounting` أو `cgma-fpa`
- **أزمة سيولة** → `ctp-treasury` فورًا، ثم `frm-risk-management` للوقاية
- **شك في موظف أو مورد** → `cfe-forensic-accounting`
- **إقرار زكاة/ضريبة** → `socpa-saudi-zakat` أو `vat-gcc-tax` أو `ea-us-tax` حسب البلد
- **بيع الشركة أو شريك جديد** → `cva-business-valuation`
- **رواتب وموظفون** → `cpp-payroll`

## ⚠️ حدود مهمة (اقرأها مرة واحدة)

- الفريق ينجز العمل كاملًا ويجهّزه، لكن **التوقيع النظامي** (اعتماد قوائم مراجَعة، تقديم إقرارات رسمية بصفة مرخصة، تقييم قضائي) يتطلب مهنيًا مرخصًا في بلدك.
- النسب والحدود النظامية (ضرائب، تأمينات) تتغير — الوكلاء مدربون على التحقق من المصدر الرسمي قبل الجزم، وساعدهم بذكر بلدك وتاريخ العملية.
- كل الوكلاء يرفضون أي تلاعب أو تهرب، ويقترحون البديل النظامي دائمًا.
