# محرك تطبيقات — خمسة تطبيقات من كود واحد

المحرك بيدعم **ثلاث أنواع** من التطبيقات:

- **`scanner`** — صورة ← جواب. كاميرا، تحليل، نتيجة.
- **`program`** — خطة يومية. جلسات، مؤقّت، سلسلة أيام، تذكير.
- **`audio`** — محاضرة ← مادة مذاكرة. تسجيل، تفريغ لحظي، تحليل، مراجعة.

الشاشات المشتركة (onboarding، paywall، التسعير، الإعدادات، التخزين، الثيم)
وحدة للنوعين. تطبيق جديد = ملف محتوى، مش مشروع.

| الحزمة | التطبيق | السؤال اللي بيجاوبه |
| --- | --- | --- |
| `dashlight` | **لمبات السيارة** | شو معنى هاللمبة اللي ولعت؟ أقدر أكمل سواقة؟ قديش التصليح؟ |
| `bugscan` | **ماسح الحشرات** | شو هالحشرة؟ هاي القرصة خطيرة؟ |
| `goldscan` | **فاحص الذهب** | شو عيار هالقطعة؟ أصلية ولا مطلية؟ قديش بتسوى؟ |
| `womensfit` | **تمارين البيت** | خطة ٤ أسابيع، بدون معدات وبدون قفز |
| `dogtrain` | **تدريب الكلاب** | ١٢ جلسة تدريب بالتعزيز الإيجابي |
| `mahdar` | **مَحضَر** | شو صار بالمحاضرة؟ شو الواجبات؟ شو رح يجي بالامتحان؟ |

الشاشات والـ API والدفع والسجل — كلها مشتركة. الفرق بين التطبيقين ملف
إعداد واحد تحت `src/scanners/`، فيه الـ prompt وعناوين الأقسام والأسئلة
والألوان. **إضافة تطبيق ثالث = ملف واحد جديد.**

## نسخة الـ SDK

المشروع مثبّت على **Expo SDK 54** عن قصد، لأنه النسخة اللي بيدعمها تطبيق
Expo Go على جهاز المطوّر. Expo Go بيدعم SDK واحد بس، فترقية المشروع بتكسر
التشغيل على الجهاز فوراً.

لو رقّيت لاحقاً: `expo-image-manipulator` و `@react-native-async-storage`
غيّروا الـ API بين 54 و 57 (`multiSet`/`multiRemove` صاروا
`setMany`/`removeMany`)، و `newArchEnabled` و `edgeToEdgeEnabled` انشالوا من
إعدادات app.config.

## شغّله

```bash
npm install
cp .env.example .env          # وحطّ ANTHROPIC_API_KEY
npx expo install --check      # شغّله مرة على جهازك للتأكد من توافق النسخ

npx expo start                       # لمبات السيارة (الافتراضي)
SCANNER=bugscan npx expo start       # ماسح الحشرات
SCANNER=goldscan npx expo start      # فاحص الذهب
SCANNER=womensfit npx expo start     # تمارين البيت
SCANNER=dogtrain npx expo start      # تدريب الكلاب
```

افتح Expo Go على تلفونك وامسح الـ QR. لازم التلفون واللابتوب على نفس شبكة
الواي فاي — التطبيق بيلاقي الـ API لحاله من عنوان سيرفر التطوير.

## قرارات مقصودة

**مفتاح الـ API ما بيوصل للتطبيق أبداً.** الصورة بتروح لـ `app/api/scan+api.ts`
اللي بيشتغل على الخادم، وهو اللي بينادي Claude. لو حطيت المفتاح بالتطبيق
نفسه، أي حدا بيقدر يستخرجه من الحزمة.

**قفل السلامة بالخادم، مش بالـ prompt.** الـ prompt بيمنع النموذج من طمأنة
المستخدم على حالة خطيرة — بس الـ prompt مش ضمانة. `clampForSafety()`
بيفرض: نتيجة `critical` ما بتقدر تطلع `verdictLevel: "ok"` مهما قال النموذج،
وثقة منخفضة بترفع مستوى الحذر تلقائياً.

**مخرجات مقيّدة بـ schema.** الرد بيرجع بشكل مضمون حسب `RESULT_SCHEMA`،
فما في تحليل نصوص هش بالتطبيق.

**تصغير الصورة قبل الرفع.** ١٠٢٤ بكسل عرض و JPEG بجودة ٠٫٧ — دقة نفس الشي
للرمز أو الحشرة، بس أسرع وأرخص بكتير من صورة كاملة بعدة ميغابايت.

**إفصاح الـ AI ضمن الـ onboarding.** آبل من نوفمبر ٢٠٢٥ بترفض التطبيقات اللي
بتستخدم خدمة AI طرف ثالث بدون شاشة إفصاح واضحة. هي مبنية بالـ onboarding.

**فحص مجاني واحد بعدين hard paywall.** `FREE_SCANS` في `src/storage.ts`.
المستخدم بيشوف اللحظة السحرية مرة، وبعدها الجدار — الـ hard paywall بيحوّل
أعلى بخمس مرات من الـ freemium.

## RevenueCat

`react-native-purchases` وحدة أصلية، فما بتشتغل بـ Expo Go. التطبيق بيشتغل
بوضع مجاني بدونها عشان تقدر تجرّب اليوم. لما تجهز للدفع:

1. اعمل منتجات الاشتراك بـ App Store Connect / Play Console.
2. اربطها بـ RevenueCat مع entitlement اسمه `pro`.
3. حطّ `EXPO_PUBLIC_RC_IOS_KEY` و `EXPO_PUBLIC_RC_ANDROID_KEY` بـ `.env`.
4. `npx expo run:ios` أو EAS build — Expo Go ما رح تكفي.

## ناقص بحزمة الذهب

التقييم بيرجع نطاق تقديري **للغرام**، مش سعر القطعة — لأن السعر الحقيقي =
الوزن × سعر الذهب اللحظي، وما في مصدر سعر مربوط بعد. لما تربط مصدر أسعار،
احسبها بـ `app/api/scan+api.ts` وضيفها على `cost` قبل ما ترجع النتيجة.
وقتها بتقدر تضيف خانة وزن بشاشة النتيجة وتطلع رقم نهائي.

## مَحضَر — ليش التقنية مبنية هيك

الفكرة المالية بالتطبيق كلها بهالسطر: **التفريغ اللحظي مجاني، والتفريغ الدقيق
بالطلب.**

- **الكاتب المباشر** — `expo-speech-recognition` بيشتغل على الجهاز نفسه
  (SFSpeechRecognizer على iOS و SpeechRecognizer على أندرويد). النص بيطلع
  والدكتور عم يحكي، **بدون ولا API call**، وبيشتغل بدون إنترنت — والقاعات
  عادةً تحت الأرض.
- **التفريغ الدقيق** — ElevenLabs Scribe، بس لما الطالب يضغط "أعد التفريغ من
  التسجيل" أو لما الكاتب المباشر ما طلّع إشي. لو كل محاضرة راحت على التفريغ
  المدفوع، الهامش بينزل تحت الصفر بأي سعر اشتراك طالب بيدفعه.
- **النبرة** — القياس (`metering`) بنجمعه أصلاً، والتحليل بيصير على الجهاز:
  المقارنة مع **الوسيط المتحرّك لصوت الدكتور نفسه** (نافذة دقيقتين)، مش مع رقم
  ثابت — لأن دكتور هادي بقاعة هادية ودكتور عالي بقاعة عالية بيعطوا dB مختلفة
  تماماً. يعني الميزة اللي بتخلي التطبيق يستاهل الاشتراك **ما بتكلف ولا سنت**.

### تفاصيل لازم تنتبه لها

- **التسجيل 16 kHz مونو** مش تنازل: كل محرك تفريغ بينزّل العينة لـ 16 kHz
  قبل ما يشتغل، فالـ 44.1 kHz ستيريو بينرمى عند الوصول. الفرق حقيقي: محاضرة
  ساعة ونص ≈ 22 MB بدل ≈ 86 MB من داتا الطالب.
- **التسجيل بالخلفية بدّه dev build** — الـ config plugins ما بتشتغل بـ
  Expo Go. بـ Expo Go التسجيل بيشتغل والشاشة فاتحة بس، والكاتب المباشر بينطفي
  بهدوء (الوحدة الأصلية مش موجودة) والنص بيجي من التفريغ بعد المحاضرة.
- **`language_code` مقصود إنه فاضي** بطلب Scribe. محاضراتنا بتتنقّل بين عربي
  وإنجليزي بنص الجملة، وتثبيت اللغة بيطفي بالضبط الميزة اللي بتتعامل مع هيك.
- **الصوت بينرفع streaming** (`uploadAsync` من `expo-file-system/legacy`) مش
  base64 داخل JSON — base64 بيزيد الحجم الثلث وبيمرّق التسجيل كله من ذاكرة
  الـ JS، وهاد بيقتل أجهزة أندرويد المتوسطة بمحاضرة طويلة.
- **النص بينحفظ كل ١٥ ثانية**، والصوت بينتقطّع كل **٥ دقايق**. ملف `.m4a`
  الواحد ما بينقرا أبداً قبل ما ينسكّر، فمحاضرة ساعة ونص بملف واحد معناها إن
  أي قتل مفاجئ بيروّح التسجيل كله. بالتقطيع، كل مقطع غير الأخير بيكون مسكّر
  وجاهز للتشغيل لحاله — يعني أسوأ خسارة ٥ دقايق مش ساعة ونص. الكلفة جزء من
  الثانية عند كل تدوير (١٨ مرة بمحاضرة ساعة ونص)، والكاتب المباشر ما بينقطع
  لأنه جلسة منفصلة.
- **المشغّل بيوصّل المقاطع** كأنها تسجيل واحد: `locate()` بتحدد أي مقطع فيه
  اللحظة وأي ثانية جواته، وكل مقطع بينفرّغ لحاله وبتنزاح توقيتاته على خط زمن
  المحاضرة. حدود المقاطع مغطّاة بفحوصات لأن الغلط فيها بيشغّل صوت غلط بهدوء.
