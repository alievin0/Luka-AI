# 🤖 عقل وجسم روبوت حقيقي مستقل — دليل شامل + كود جاهز

هذا المجلد يحتوي على **نواة عقل روبوت حقيقية** تعمل بالذكاء الاصطناعي (Claude)،
مبنية بحيث تجربها على اللابتوب اليوم، وتنزّلها على روبوت فيزيائي لاحقاً بدون
تغيير العقل نفسه — فقط تبدّل "الجسم".

---

## 1. الفكرة الأساسية: الروبوت = عقل + جسم + حلقة

أي روبوت مستقل في العالم (من Roomba إلى Tesla Optimus) مبني على نفس الحلقة:

```
        ┌─────────────────────────────────────────┐
        │              حلقة الاستقلالية            │
        │                                         │
        │   1. أحسّ (Sense)   ← كاميرا، مايك،      │
        │                       مسافة، بطارية      │
        │   2. أفكّر (Think)  ← العقل (AI) يقرر    │
        │   3. أنفّذ (Act)    ← محركات، صوت،       │
        │                       حركة               │
        │   4. أرجع للخطوة 1                       │
        └─────────────────────────────────────────┘
```

في هذا المشروع:

| الجزء | أين هو | ماذا يفعل |
|---|---|---|
| **العقل** | `mind/brain.py` | حلقة إحساس→تفكير→تنفيذ، يستخدم Claude كطبقة التفكير العليا |
| **الأدوات** | `mind/tools.py` | الأفعال المتاحة للعقل (تحرّك، تكلّم، دوّر، تذكّر...) |
| **الذاكرة** | `mind/memory.py` | ذاكرة دائمة على القرص — الروبوت يتذكر بين الجلسات |
| **واجهة الجسم** | `body/interface.py` | العقد بين العقل وأي جسم (محاكاة أو حقيقي) |
| **جسم المحاكاة** | `body/sim_body.py` | جسم وهمي على الشاشة — جرّب العقل بدون أي قطع |
| **جسم حقيقي** | `body/pi_body.py` | مثال Raspberry Pi: محركات + حساس مسافة + صوت |

**النقطة الذهبية:** العقل لا يعرف إذا الجسم حقيقي أو محاكاة. هذا يعني أنك
تطور وتجرب كل شيء على اللابتوب، وعندما يجهز الجسم الفيزيائي تكتب فقط
`--body pi` وينتقل نفس العقل للروبوت الحقيقي.

---

## 2. تشغيل العقل الآن (محاكاة — بدون أي قطع)

```bash
cd robot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...   # مفتاحك من console.anthropic.com

python run.py --body sim --goal "استكشف الغرفة وقدّم نفسك"
```

سترى الروبوت "يفكر" ويتحرك ويتكلم على الشاشة، ويكتب ذاكرته في
`robot_memory.md`. هذا هو نفس العقل الذي سينزل على الروبوت الحقيقي.

---

## 3. عمارة العقل — ثلاث طبقات (مهم جداً)

خطأ شائع: محاولة جعل الـ AI يتحكم بكل شيء مباشرة. الروبوتات الحقيقية
تُبنى بثلاث طبقات سرعة:

```
┌────────────────────────────────────────────────────────┐
│ الطبقة 3: التفكير العالي (Claude) — كل 1-5 ثواني        │
│ "أرى شخصاً أمامي، سأتوقف وأسلّم عليه"                  │
│ → هذا ما يبنيه هذا المشروع                              │
├────────────────────────────────────────────────────────┤
│ الطبقة 2: التحكم (كودك المحلي) — كل 10-50 ملي ثانية     │
│ تنفيذ "تقدم 1 متر" = أوامر سرعة للمحركات + تصحيح       │
│ → تكتبها بايثون عادي أو ROS 2                           │
├────────────────────────────────────────────────────────┤
│ الطبقة 1: ردود الفعل (Reflexes) — فورية، بدون AI        │
│ حساس المسافة < 20 سم → توقف فوراً (مكتوبة في الجسم)     │
│ → السلامة لا تعتمد على AI أبداً                         │
└────────────────────────────────────────────────────────┘
```

الـ AI بطيء نسبياً (ثانية أو أكثر لكل قرار) — لذلك لا يقود المحركات
مباشرة، بل يعطي **نوايا عالية المستوى** ("اذهب للمطبخ") والطبقات الأدنى
تنفذها بسرعة وأمان. ملف `body/pi_body.py` يطبق ردود الفعل (الطبقة 1)
داخل الجسم نفسه.

## 4. الجسم الفيزيائي — خارطة الطريق الواقعية

روبوت "مثل الإنسان" يمشي على رجلين هو أصعب مشروع في الروبوتات (شركات
بمليارات الدولارات ما زالت تطوره). الطريق الصحيح هو التدرج — كل مرحلة
تعطيك روبوتاً حقيقياً يعمل، ونفس العقل ينتقل معك:

### المرحلة 1: روبوت بعجلات + رأس (شهر–شهرين، ~150–400 دولار)
أفضل نقطة بداية بلا منازع. تتعلم فيها 90% من المهارات المطلوبة.

| القطعة | الخيار | السعر التقريبي |
|---|---|---|
| الكمبيوتر (دماغ الجسم) | Raspberry Pi 5 (8GB) | ~$80 |
| الحركة | شاسيه بعجلات + 2 محرك DC + درايفر L298N أو TB6612 | ~$30–60 |
| الرؤية | Raspberry Pi Camera Module 3 | ~$25 |
| السمع/الكلام | مايك USB + سماعة صغيرة | ~$20 |
| الحساسات | Ultrasonic HC-SR04 (مسافة) + IMU MPU6050 (توازن/اتجاه) | ~$10 |
| الرقبة | 2 سيرفو SG90/MG996 (pan/tilt للكاميرا) | ~$10 |
| الطاقة | بطارية ليثيوم + منظم جهد | ~$30 |

- الاتصال بالإنترنت (WiFi) لأن العقل (Claude) يعمل سحابياً.
- ملف `body/pi_body.py` مكتوب لهذه المرحلة بالضبط.

### المرحلة 2: شكل إنساني ثابت — جذع وذراعان ورأس (3–6 أشهر، ~500–1500 دولار)
- **InMoov**: أشهر روبوت إنساني مفتوح المصدر بالعالم، تطبعه بطابعة 3D
  (المخططات مجانية على inmoov.fr) — ذراعان وأصابع ورأس يتحرك.
- سيرفوهات قوية (MG996R للأصابع، سيرفوهات عزم عالي للأكتاف).
- تضعه على قاعدة العجلات من المرحلة 1 → روبوت إنساني الشكل متحرك.

### المرحلة 3: المشي على رجلين (سنوات + ميزانية كبيرة)
- المشي الديناميكي يحتاج محركات خاصة (actuators) بآلاف الدولارات ونظم
  تحكم توازن بتردد 1000Hz.
- الخيار العملي: روبوت جاهز مثل **Unitree G1** (~$16,000) وتنزّل عقلك
  عليه عبر SDK الخاص به — لأن Unitree توفر واجهة برمجية، وعقلك هنا
  مصمم أصلاً ليركب فوق أي واجهة جسم.

### أدوات ستحتاج تتعلمها بالتوازي
- **Python** (أساسي — كل الكود هنا بايثون).
- **ROS 2** (نظام تشغيل الروبوتات القياسي) — ليس شرطاً للمرحلة 1، لكنه
  الطريق الاحترافي من المرحلة 2. واجهة `RobotBody` هنا مصممة بحيث تكتب
  لاحقاً `ros_body.py` يترجم نفس الدوال إلى مواضيع ROS.
- **محاكي**: Gazebo أو Webots أو Isaac Sim — لتجربة الجسم قبل تركيبه.

## 5. كيف يعمل العقل داخلياً (`mind/brain.py`)

1. **الإحساس**: يقرأ من الجسم لقطة كاميرا (إن وجدت)، مسافة العائق،
   البطارية، وآخر ما سمعه من المايك.
2. **التفكير**: يرسل كل ذلك إلى Claude مع الهدف الحالي والذاكرة، ومعه
   قائمة الأدوات (تحرك، دوّر، تكلم، حرّك الرأس، تذكّر، انتظر).
3. **التنفيذ**: كل أداة يطلبها Claude تُنفذ عبر واجهة الجسم، والنتيجة
   ترجع له فوراً — فيكمل التفكير بناء على ما حدث فعلاً.
4. **الذاكرة**: أداة `remember` تكتب ملاحظات دائمة في `robot_memory.md`
   تُحقن في كل جلسة قادمة — الروبوت يتعلم بيئته مع الوقت.
5. **الأمان**: زر الطوارئ (Ctrl+C أو أمر "قف") يوقف المحركات مباشرة من
   طبقة الجسم بدون انتظار الـ AI، وميزانية خطوات لكل دورة تمنع الحلقات
   اللانهائية.

## 6. تنزيل العقل على الروبوت الحقيقي

على الـ Raspberry Pi المركّب في الروبوت:

```bash
git clone <هذا المستودع>
cd Luka-AI/robot
pip install -r requirements.txt
pip install gpiozero  # للتحكم بالمحركات
export ANTHROPIC_API_KEY=sk-ant-...

python run.py --body pi --goal "استكشف المكان وتجنب العوائق"
```

عدّل أرقام الـ GPIO في أعلى `body/pi_body.py` حسب توصيلاتك (الأرقام
الافتراضية موثقة هناك). أي حساس غير موصول يتجاهله الجسم بأمان ويكمل.

---

## 7. الخطوات القادمة المقترحة

1. جرّب المحاكاة اليوم وعدّل شخصية الروبوت في `mind/brain.py`
   (المتغير `PERSONALITY`).
2. اشترِ قطع المرحلة 1 وركّب قاعدة العجلات.
3. أضف التعرف على الكلام (whisper) والنطق (Piper TTS يعمل محلياً على
   الـ Pi) — الواجهات جاهزة في `body/interface.py`.
4. عند الانتقال لـ ROS 2: اكتب `body/ros_body.py` يطبّق نفس
   `RobotBody` — العقل لن يتغير سطراً واحداً.
