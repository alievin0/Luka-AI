# العالَم

ألف نفس، ثلاثة بيوت، وملف واحد على قرصك.

يعيشون: يولدون، يتعلّمون، يشتغلون، يتشاجرون، يعتزلون. ويخرج من حياتهم شيء واحد
يهمّك: **أفكار لها جسد**. لا عناوين لامعة — أجساد فيها سبعة أعضاء، وأي فكرة
ينقصها عضو لا تقف أمامك.

أنت الملك. ما عندك موظف هنا، عندك سكّان.

---

## شغّله الآن

ما يحتاج تنزيل ولا إنترنت ولا مفتاح. بايثون ٣ وبس:

```bash
cd world
python3 king.py found          # يخلق العالم: ١٠٠٠ نفس في ٣ بيوت
python3 king.py run 60         # يمرّ ٦٠ يوماً — ثوانٍ معدودة
python3 king.py ideas --top 10 # لوح الأفكار مرتّباً
python3 king.py idea 903       # جسد الفكرة، عضواً عضواً، وتاريخها
```

العالم كله في `world/world.db`. انسخه، خُذه معك، ارجع له بعد سنة.
امسحه = العالم انتهى. `python3 king.py found --force` يبدأ من جديد.

## البيوت الثلاثة

كل بيت يبدأ من مكان مختلف، ولذلك ينتج أفكاراً مختلفة — والمقارنة بينها هي الفائدة.

| البيت | عقيدته |
|---|---|
| **بيت الوجع** | لا تبدأ من فكرة. ابدأ من واحد ينزف ويدفع اليوم ليوقف النزيف. |
| **بيت الحيلة** | لا تنافس على نفس التكلفة. امسك حيلة تخليك أرخص عشر مرات أو أسرع عشر مرات. |
| **بيت السوق** | أحسن منتج بلا طريق يوصله ميت. ابدأ من جمهور توصله كل أسبوع ببلاش. |

`python3 king.py houses` يعطيك الترتيب — **بالنتيجة، لا بالنشاط**. بيت ينتج ٥٠٠ فكرة
ولا واحدة منها كاملة، متأخر عن بيت أنتج ثلاثاً.

## الوظائف

| الوظيفة | شغلها |
|---|---|
| **كشّاف** | يرجع بملاحظة خام من السوق. ملاحظة، ليست فكرة. |
| **صانع** | يحوّل الملاحظة إلى جسد: عرض، جمهور، حصن. |
| **مُشرّح** | يهاجم الفكرة ويكشف العضو الناقص. أخطر وظيفة في البيت. |
| **مُحاسب** | يحسب الكلفة والسعر، ويقول متى تموت الفكرة حسابياً. |
| **تاجر** | ينتزع الدليل: هل دفع أحد فعلاً. أصعب عضو وأصدقه. |
| **معلّم** | يرفع مهارة الصغار ولا ينتج فكرة بنفسه. |
| **شيخ البيت** | يختار ما يُرفع إليك. توقيعه سمعته. |

## الأعضاء السبعة

هذا قلب النظام كله. الفكرة تولد بعضو واحد وتموت إن لم تُنبت الباقي:

| العضو | السؤال الذي يجيب عليه |
|---|---|
| **الوجع** | مَن ينزف بالضبط، وكيف يبدو النزيف |
| **التكرار** | كم مرة يتكرر: يومي/أسبوعي وإلا ميت |
| **الثمن الحالي** | كم يدفع اليوم ليتحمّله — بالدينار |
| **الدليل** | واحد دفع فعلاً، باسمه وتاريخه |
| **الكلفة** | كم يكلّفنا نخدمه، وهل يبقى فرق |
| **الطريق** | كيف نوصله كل أسبوع بلا حرق فلوس |
| **الحصن** | ليش الثاني اللي يقلّدنا يخسر |

### البوابات — لماذا لا تصل إليك فكرة جميلة فارغة

الدرجة ليست معدّلاً. عضو ضعيف واحد يقصّ الدرجة مهما بلغ الباقي:

| الشرط | السقف | السبب |
|---|---|---|
| لا تكرار | **٣٥** | وجع يصير مرة بالسنة ما يبني شركة |
| لا دليل دفع | **٥٥** | ولا واحد دفع — كل الباقي رأي |
| لا نعرف ثمنه الحالي | **٦٢** | ما نعرف كم يدفع، فما نعرف كم نطلب |
| لا طريق للوصول | **٧٠** | منتج ممتاز بلا باب |
| ينقصها أي عضو | **٨٥** | جسد ناقص |

أثقل عضو هو **الدليل** (٢٠٪ من الوزن). والسبب ليس نظرياً: هذا بالضبط ما كُتب
في `PROJECT_STATUS.md` في مستودعك الآخر — *«صفر دليل مباشر من عميل»* بعد
١٢٦٢ اختباراً ناجحاً ومحرّك أقوى من منافسين ممولين. النظام هنا مبني ليمنع
تكرار ذلك.

وإذا هُدم عضو في فكرة **بعد** رفعها إليك، تُسحب من لوحك ويُكتب سبب السحب. لا
يقف أمامك جسد ناقص، ولو وقف كاملاً بالأمس.

## أوامرك

```bash
python3 king.py status                    # أين العالم الآن
python3 king.py brief                     # إحاطة اليوم
python3 king.py houses                    # ترتيب البيوت
python3 king.py ideas --top 10            # اللوح
python3 king.py ideas --status ميتة       # ما مات ولماذا
python3 king.py idea 903                  # جسد فكرة وتاريخها
python3 king.py agent 317                 # سيرة نفس واحدة
python3 king.py fund 903 500              # تموّلها — ويُقيَّد في خزينتك
python3 king.py kill 903 "السبب"          # تقتلها، ويُكتب سببك في التاريخ
python3 king.py decree "..." --set nominate_at=80
```

**التمويل يرفض الجسد الناقص.** إذا أصررت، `--anyway` يمرّرها — ويُكتب في تاريخ
العالم أنك موّلتها ناقصة. هذا ليس تأنيباً؛ هذا سجلّ ترجع له بعد ستة أشهر.

**المرسوم يغيّر قانون العالم نفسه**، لا فكرة واحدة:

```bash
python3 king.py decree "لا أريد إلا ما تجاوز 80" --set nominate_at=80
python3 king.py decree "فكّروا أكثر"           --set think_budget=24
```

## العقل: ثلاثة أوضاع

| الوضع | كيف | ما الذي يعطيك |
|---|---|---|
| **offline** (الافتراضي) | لا شيء | العالم يعيش ويشتغل ويرتّب. النصوص تُركّب من معاجم. |
| **ollama** | `WORLD_MIND=ollama` | نموذج محلي على نفس اللابتوب. مجاني، أبطأ. |
| **claude** | `WORLD_MIND=claude` + `ANTHROPIC_API_KEY` | تفكير حقيقي في اللحظات المهمة. |

```bash
WORLD_MIND=claude ANTHROPIC_API_KEY=sk-ant-… python3 king.py run 30 --budget 12
```

### قل هذا بوضوح

**وضع `offline` ليس تفكيراً.** العالم فيه يعيش فعلاً — الوظائف تشتغل، الأعضاء
تنبت، المُشرّحون يهدمون، البوابات تقصّ، الترتيب صادق. لكن **نصّ** الأعضاء مركّب
من معاجم، ولن يأتيك بفكرة لم تخطر لأحد. استخدمه لتشغيل العالم بلا فاتورة، ولفهم
كيف يتصرّف، وللتجارب الطويلة.

**الأفكار الحقيقية تحتاج نموذجاً.** فعّل `claude` أو `ollama`، وعندها يكون ما
يصعد إليك ناتج تفكير لا تركيب.

### التكلفة

ميزانية التفكير (`--budget`) تحدّ عدد الوكلاء الذين يستدعون النموذج يومياً.
الألف الباقون يشتغلون بقواعد — وهذا ليس غشاً، هذا ما يفعله البشر أغلب أيامهم.
الاختيار ليس عشوائياً: تذهب الميزانية لأعلى أولوية — فكرة واعدة × وكيل ماهر ×
عضو ناقص، والدليل يأخذ أولوية إضافية لأنه أغلى عضو.

`--budget 0` = بلا أي استدعاء. `python3 king.py run` يطبع كم استُدعي وكم توكن.

## الفحوصات

```bash
python3 test_world.py
```

١٦ فحصاً. كل واحد وُجد لأن شيئاً انكسر فعلاً: عضو الوجع كان يختار وجعاً عشوائياً
غير وجع فكرته، وستة شيوخ كانوا يرفعون الفكرة نفسها في اليوم نفسه، وفكرة رُفعت ثم
هُدم عضو فيها وبقيت واقفة أمام الملك.
